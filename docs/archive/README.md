# Archive

`opnsense-plan-sep2026/` is the project's earlier planning by Isaac Lares (September 2026). It was moved here unchanged from the repository root on 2026-11-15, when the project switched to the stripped-down design in `docs/DEVELOPMENT_PLAN.md` (Linux namespaces and nftables in one Ubuntu VM instead of an OPNsense lab).

Some ideas carry over directly: a deterministic validator over AI output, predefined response actions, human approval before enforcement, and temporary containment.
